## What to expect

When Quiverstone's public API is released, this section will cover:

- **Authentication** — API key and OAuth flows for programmatic access.
- **Resources** — endpoints for Organizations, Accounts, Customers, Teams, Groups, and Roles.
- **Role assumption** — programmatic role assumption for CI/CD pipelines and automation.
- **Webhooks** — event notifications for resource changes, role assumptions, and membership updates.
- **SDKs and examples** — client libraries and language-specific quickstarts.

## In the meantime

Most Quiverstone functionality is available today through the web console at [app.quiverstone.io](https://app.quiverstone.io). If you have a specific automation need that requires programmatic access before the public API ships, [contact support](mailto:support@quiverstone.io) — we're prioritizing early API access for customers with concrete use cases.
