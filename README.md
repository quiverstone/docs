# Core Public Documentation

This repository contains the core software for Quiverstone. It is organized into several key directories: `agents/`, `code/`, `marketing/`, and `platform/`.

## Agents
- Contains agent configuration and personal files for each AI agent.
- Includes `AGENTS.md`, `HEARTBEAT.md`, `SOUL.md`, and `TOOLS.md` which define agent roles, daily plans, and coordination.

## Code
- The main codebase resides here, with packages, scripts, and modules.
- Run `npm install` to install dependencies.
- Use `npm run update-submodules` to ensure submodule dependencies are up to date.

## Marketing
- Holds marketing assets and strategy documents.

## Platform
- Contains platform-specific configurations and deployment scripts.
