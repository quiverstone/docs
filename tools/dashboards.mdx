# Dashboards

<Note>
**Status:** In Development - This feature is currently under development and will be available in a future release.
</Note>

## Overview

Dashboards in Quiverstone will provide customizable, at-a-glance views of your AWS accounts, organizations, and resources. Create personalized dashboards to monitor what matters most to you.

## Planned Features

### Dashboard Types
- **Overview Dashboard** - High-level summary of all accounts and organizations
- **Customer Dashboard** - Customer-specific views for MSPs
- **Account Dashboard** - Detailed view of individual accounts
- **Resource Dashboard** - Track specific AWS resources across accounts
- **Security Dashboard** - Security posture and compliance monitoring

### Widgets and Components
- Account status widgets
- Resource count summaries
- Cost tracking charts
- Compliance status indicators
- Recent activity feeds
- Custom metric displays

### Customization
- Drag-and-drop widget placement
- Customize widget sizes and layouts
- Filter data by organization, customer, or account
- Save and share dashboard configurations
- Schedule dashboard reports

## Use Cases

**For MSPs:**
- Customer health overview
- SLA monitoring across customers
- Resource utilization trends
- Billing and cost tracking

**For Platform Teams:**
- Infrastructure health monitoring
- Resource optimization opportunities
- Security compliance status
- Incident tracking
